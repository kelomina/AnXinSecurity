下载安装

两种方式把安芯安全（AnXin Security）装进你的 Windows：直接下载开箱即用的 NSIS 安装包，或者用 Node.js 与 Rust 工具链从源码构建属于你的版本。 本页还整理了开发环境搭建步骤与常见问题排查（Troubleshooting）。

v1.0.0 Windows 10 / 11 · x64 NSIS 安装包 MIT 开源
获取安装包 环境要求 开发环境搭建 生产构建 问题排查

从 GitHub Releases 获取安装包

前往仓库的 Releases 页面，下载形如 AnXinSecurity_1.0.0_x64-setup.exe 的 NSIS 安装包，双击安装即可；也可以直接浏览源码自行构建。

环境要求

安装前先确认环境Requirements

直接安装只需系统满足运行要求；想从源码构建，再准备一套前端与 Rust 构建工具链。

运行要求 · Runtime

下载安装包直接使用时，只需要：

  • Windows 10 / 11 操作系统（x64）
  • WebView2 运行时（Windows 10/11 已内置，无需单独安装）
从源码构建要求 · Build from Source

参与开发或自行构建安装包时，还需要：

  • Node.js ≥ 18
  • Rust 工具链（rustc ≥ 1.95，cargo ≥ 1.95）
  • Visual Studio 2019+ Build Tools（C++ 开发工作负载）
  • WebView2（Windows 10/11 已内置）
开发环境

三步搭好开发环境Dev Setup

克隆、安装、启动——每一步的命令都可以一键复制到终端执行。

1

克隆项目

从 GitHub 拉取仓库并进入项目目录。

bash 
git clone https://github.com/kelomina/AnXinSecurity.git
cd AnXinSecurity
2

安装依赖

使用 npm 安装前端与 Tauri CLI 依赖。

bash 
npm install
3

启动开发模式

启动完整开发模式（前端 + Tauri），编译完成后会自动打开应用窗口。

bash 
npm run dev
首次启动会先启动 Vite 开发服务器（端口 1421），再编译 Rust 后端（首次约 5-10 分钟），最后打开 Tauri 应用窗口。
生产构建

一条命令，产出安装包Production Build

构建生产版本（前端 + 安装包），生成的 NSIS 安装包位于 src-tauri/target/release/bundle/nsis/AnXinSecurity_1.0.0_x64-setup.exe。

bash 
npm run build

快速问题排查

遇到问题？先看这里Troubleshooting

网络访问 crates.io 缓慢时，可以配置 Cargo 国内镜像源（写入 ~/.cargo/config.toml）：

~/.cargo/config.toml 
[source.crates-io]
replace-with = 'tuna'
[source.tuna]
registry = "sparse+https://mirrors.tuna.tsinghua.edu.cn/crates.io-index/"
[http]
check-revoke = false

Vite 开发服务器默认使用端口 1421。先找到占用端口的进程 PID，再结束它：

cmd 
netstat -ano | findstr :1421
taskkill /F /PID <PID>

按以下三项逐一检查：

  • 检查 native/bin/win32-x64/ 目录是否存在
  • 确保 DLL 未被杀毒软件隔离
  • 以管理员身份运行应用

清理构建缓存后重新编译，通常可以解决大多数增量编译异常：

bash 
cd src-tauri
cargo clean
cargo build
