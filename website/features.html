功能特性，逐项拆解

安芯安全（AnXin Security）围绕四大能力域构建完整防线：Axon / Raven 双引擎实时文件扫描、 ETW 行为监控与生命周期追踪、威胁拦截与进程控制，以及 AES-128-GCM 加密隔离区。本页逐一拆解每项能力的原理与实现，并附上功能全景、 技术架构与 Fluent 2 设计系统速览。

能力域 01 · 实时扫描

双引擎研判，
恶意文件无处落脚Real-time File Scanning

  • Axon ML 机器学习引擎以 Apache 2.0 协议独立开源的机器学习引擎（Machine Learning Engine），预编译 DLL 在本机运行，判定不出本地。
  • Raven 引擎 + 签名引擎基于签名数据库（Signature Database）的精准匹配，与 Axon 组成双引擎交叉研判，两者均为与应用深度集成的引擎 DLL。
  • 文件与进程内存扫描既检查落盘文件，也支持进程内存扫描（Memory Scanning），潜伏在运行中进程里的威胁同样难逃检测。
  • 扫描判决缓存由 scan_result_cache_service 维护判决缓存（Verdict Cache），重复检测近乎零开销。
  • 扫描限制可配置扫描限制集中在 config/app.json，例如 maxFileSizeMB 控制参与扫描的单文件大小上限。

能力域 02 · 行为监控

看得见每个进程的
一举一动ETW Behavior Monitoring

  • ETW 实时会话基于 Event Tracing for Windows 的会话（Session）实时捕获系统事件，监控进程行为，由 etw_service 管理会话、规则与解析。
  • 可配置匹配规则config/etw_match_rules.json 定义 provider、operation、severity、threatType、recommendAction 与目标匹配条件——规则可解释、可复现。
  • 行为数据落地 SQLite行为事件经 behavior_service 写入 SQLite（sqlx ORM），行为数据库路径可在主配置中调整。
  • 单进程行为时间线行为生命周期追踪（Behavior Lifecycle）为单个进程构建完整时间线：进程创建、注册表写入、文件落盘一览无余。

能力域 03 · 威胁拦截

先挂起，再决策，
处置权交还给你Threat Interception

  • 实时拦截实时拦截并隔离恶意文件，由 interception_service 串联检测与响应链路。
  • 进程挂起 / 恢复 / 终止支持对可疑进程执行挂起（Suspend）、恢复（Resume）与终止（Terminate），拦截先冻结、后处置。
  • 用户决策弹窗关键处置不擅自代劳：拦截发生时弹出用户决策弹窗（User Decision Dialog），给出建议动作，由你定夺。
  • 受保护系统进程边界csrss.exe、smss.exe、wininit.exe 等关键系统进程禁止操作，防护动作绝不动摇系统根基。
  • 自身保护拒绝操作自身进程（Self-protection），恶意样本无法借刀杀人让防护自我了断。

能力域 04 · 加密隔离

封得住，也擦得净，
误报还能救回来Encrypted Quarantine

  • AES-128-GCM 加密封存恶意文件以 AES-128-GCM 加密隔离，封存期间无法运行，由 quarantine_service 统一管理。
  • 密钥经 DPAPI 保护默认生成本机随机 AES 密钥，经 Windows DPAPI 加密后保存到 APPDATA runtime；也可通过 ANXIN_SECURITY_QUARANTINE_KEY 显式指定 32 位 hex 密钥。
  • NIST SP 800-88 三次覆写永久删除执行三次覆写安全擦除（随机数据 → 0x00 → 0xFF），符合 NIST SP 800-88 建议，不给样本复活机会。
  • 误报可恢复确认为误报（False Positive）后可一键恢复到原路径；只有你主动选择「永久删除」时才执行不可逆擦除。
