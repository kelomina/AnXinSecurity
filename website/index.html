安全设计

纵深防御，
连自身也在防线之内Security by Design

  • AES-128-GCM 加密隔离隔离区默认生成本机随机密钥，密钥经 Windows DPAPI 加密后存入用户目录。
  • NIST SP 800-88 安全擦除永久删除执行三次覆写（随机数据 → 0x00 → 0xFF），不给恶意样本复活机会。
  • 受保护进程边界csrss.exe、smss.exe、wininit.exe 等关键系统进程禁止操作，同时拒绝操作自身进程。
  • 运行时状态 DPAPI 加密允许列表与排除项写入 APPDATA 并以 DPAPI 加密、带完整性校验，绝不回写仓库配置。
  • 本地优先扫描引擎以本机 DLL 形式运行，检测与判定默认在本地完成。
